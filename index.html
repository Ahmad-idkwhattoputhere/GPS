How does GPS work?

GPS satellites transmit signals containing the time they were sent. A receiver compares that time with when the signal arrives to estimate how far away each satellite is.

Measured distance = True distance + Clock error + Measurement error

Each distance creates a possible circle around a satellite. Combining measurements lets the receiver estimate its location. In this 2D model, four satellites help estimate two coordinates and one clock-bias value.
